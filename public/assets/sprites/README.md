# Sprite assets

These PNGs are the game's sprite art. `BootScene.preload()` loads every one by key from the
`ASSET_SPECS` manifest in [`src/scenes/BootScene.ts`](../../../src/scenes/BootScene.ts); game code
references textures only by key, so the art lives entirely here.

Most are hand-drawn. The lab-floor creatures and the noble-gas gem (★ below) are **generated** by
[`scripts/gen-sprites.mjs`](../../../scripts/gen-sprites.mjs) — re-run `npm run gen:sprites` after
editing that script. (To swap one for hand-drawn art instead, overwrite the PNG at the same size and
drop it from the generator.)

## Replacing a sprite

Export a new PNG at the key's **canonical size** above and overwrite the file in the matching folder.
Phaser sizes arcade bodies from texture dimensions, so keeping the same size is a pure drop-in — no
code changes. `projectile` and `particle` are tinted at runtime, so keep their art near-neutral.

> Not loaded here (procedural by design): stage maps (`bg_tile_1..4` / `ground_tile_1..4`, shared by
> the lab-floor sectors) and the `vignette` screen effect, plus the live vector FX in `Player.ts` /
> `GameScene.ts`.
